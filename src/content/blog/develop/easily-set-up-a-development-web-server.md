## Why?
1. JavaScript勉強用にレポジトリを作って実行したコードをまとめている。

2. Webブラウザだとどういう挙動になるのか、HTMLにして可視化したい、などサーバーを立てたい事がある。

3. なるべく楽に、依存関係なく、そこそこ機能が充実したやり方を知りたい

## Bun
追加のライブラリを使わず、Bunの標準APIで実行できる。

```js
bun index.html
```
だけで`localhost:3000`にサーブできる

もっと言うと、以下のようにすると、ディレクトリ構成を反映したパスで`src/`配下のhtmlをサーブできて便利。

```js
bun ./src/**/*.html
```

## もっと求める機能
* ホットリロード
* `.ts`をうまいこと使えるようにしたい。
    * `<script src="script.ts">`を指定できるようにするのか、`.js`がなくても、いい感じに変換して指定できるようにするのかなど
