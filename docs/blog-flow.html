.astroの「---」と「<slot />」って何？
---で囲まれた先頭部分には、記事の取得や変数の準備を書きます。このブログの本番用HTMLを作るときは、ビルド側で実行されます。開発中は開発サーバーで処理されます。
<slot />は、呼び出し元が渡した中身を差し込む場所です。Layout.astroは全体の枠を用意し、そこへトップページの一覧や記事ページの内容を受け取ります。
ブラウザに届くのは生成されたHTMLです。明示的に書いた<script>などのJavaScriptは、ブラウザ側で動きます。

04
技術とライブラリの役割

    
フレームワークは全体の仕組みを担当し、ライブラリは検索や画像処理など特定の仕事を担当します。バージョンはリポジトリの依存関係に基づきます。

    
技術・ライブラリこのブログで担当すること主に動く場所

      
Astro 7.3.5ページのURLを決め、記事や部品を組み合わせてHTMLを生成する。開発・ビルド

      
TypeScript / JavaScript記事データの処理や型チェック、画像拡大などの操作を書く。ビルド／ブラウザ

      
Markdown / MDX記事を書く形式。見出し・リンク・画像などを記述する。MDXにも対応。執筆 → ビルドで変換

      
Tailwind CSS 4.3.3
独自CSS		見た目を定義する。global.cssがsite.css・article.cssなどを読み込む。ビルド → ブラウザ

      
remark / rehype / ShikiMarkdownをHTMLへ変換する途中で、埋め込み・画像キャプション・コードの色付けなどを行う。ビルド

      
Pagefind生成したページから検索データを作る。読者の検索はブラウザで処理する。ビルド／ブラウザ

      
Sharp一覧や記事に使う画像のサムネイルを作る。ビルドの前処理など

      
Satori / Resvg / BudouXSNS共有用の画像を生成する。日本語タイトルの改行も調整する。ビルド

      
pnpm / Vitepnpmは依存関係とコマンドを管理する。ViteはAstroの開発やCSS・JSのビルドを支える。開発・ビルド

    

    
技術の設定はどこにある？
package.jsonにはライブラリと実行コマンド、pnpm-lock.yamlには解決されたバージョンがあります。astro.config.mjsにはAstroの拡張、Tailwind連携、Markdown変換などの設定があります。tsconfig.jsonには型チェックと、@components/などのパス省略の設定があります。

  


  

    
05
手元で流れを確認する

    
pnpm dev
編集しながら表示を確認する。開発中は下書きも表示する。
pnpm build
画像の前処理、型チェック、HTMLなどの生成、非公開ページの検査。
pnpm preview
ビルドしたdist/のサイトを、手元で確認する。

    
公開先について確認できた範囲
設定上のURLは blog.amatatu.com。記事画像には assets.blog.amatatu.com も使われています。ホスティングサービス、自動デプロイ、DNSの設定は、このリポジトリ内では確認できませんでした。Gitにpushしたあと何が動くかは、公開先の設定で確認します。
